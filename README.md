# 个人作图工具箱

双击 [个人作图工具箱 · 磷光光谱更新版](release/磷光光谱更新版-2026-11-22/个人作图工具箱.app) 启动。打包适用于 Apple 芯片的 Mac，界面和绘图资源随应用安装。

1. 在左侧点「连接文件夹」。应用会记住所选目录，递归扫描子目录，并以可展开的文件树显示 XLSX、XLS、XLSM、XLSB、ODS、FODS、CSV、TSV、TAB、TXT 和表格型 JSON。JSON 支持记录数组和二维数组。
2. 点文件名打开该文件的单图和数据表，多工作表文件可在文件区切换。遇到带 `XAxis`、`YAxis` 等采集参数的仪器导出，应用会跳过表首参数区，并用轴名称作为列名。要更新磁盘数据，可点「重新读取」。
3. 在表格上方点击「筛选行」，选择巡点信号列、平台点数和巡点方式，再点「自动巡点」。高位平台后骤降会选择开始持续下降的第一行，近零基线后突升会从第一个明显高点开始。折线图、散点图和面积图可在右侧「拟合」按系列选择模型，查看方程、参数、R² 和有效点数。拟合取点遵循横纵轴范围，次轴上的系列使用右侧 Y 轴范围。点击「新开拟合窗口」可比较拟合模型，再点「应用到原图」。
4. 点击树里的「当前图表」可查看来源文件及工作表。点击「保存图组」可把当前拼版及数据快照保存为 `.sciplot.json`，重启后仍可在树里查看来源和打开编辑。可从「导出」另存 PNG。
5. 右侧「图表」首页可快速选择散点、折线、柱状图，线性、单指数、双指数拟合，以及坐标轴范围。点「+」展开其他图型或模型。「作图模板」可应用散点、余辉半对数、磷光光谱、蓝绿比、Arrhenius 和余辉双对数幂律预设，也可按模板应用后的首条曲线巡点。Arrhenius 使用表中已换算的倒温度与对数列。展开「拼版与自定义默认模板」，可保存导入时用的巡点方式、信号列和平台点数。
6. 打开至少两张折线图、散点图或面积图，在左侧点「合并曲线」，勾选后点「叠加为新图」。原图和合并图都能从文件树打开，也可使用「拼版视图」排在同一页。「图表」首页可切换各组数据的显示状态，也可统一或按系列设置归一化。拟合和导出使用筛选、归一化后的数据。
7. 在文件树里打开能识别的光谱表时，会自动应用磷光光谱模板，并在右侧顶部展开「光谱分峰」。模板默认画散点，以各组的 Y 最大值归一化，并标注实测峰位。选择曲线和峰数后，可逐个填写初始峰位，或将所有框留空以自动估计。点击峰形即可用固定零基线拟合，再点击同一峰形可关闭。拟合后可点「调节参数」，应用后会更新曲线、残差和 R²。显示分峰时，对数正态峰的中心和可见偏移位置会用同一分量的颜色标注。
8. 可同时点亮多个拟合模型，再点同一按钮关闭。经「+」添加的模型会显示在按钮区。图下方的残差是实测值减拟合值，光谱分峰用总拟合线计算。拼版的残差集中放在主图下方，并标出对应面板。有残差时，点「导出 PNG」会同时保存纯图和带残差的 `-residuals` 版本。
9. 主图上方的「nm ↔ eV」可在波长和光子能量之间切换，再点即可恢复原始横轴。在「图表」首页展开「波长 ↔ 能量」，可指定方向及「同步换算强度密度」。开启后会按谱密度的雅可比换算 Y，再进行归一化和拟合。自动数值横轴会依据数据范围留少量边距，也可以手动填写上下限。
10. 点击主图上方的「框选数据」，在折线图、散点图、面积图或柱状图中拖出一个矩形。左下角显示框内的数据点，点击「源数据」可查看和编辑对应的原始行。按 Esc 或点击「清空选区」可收起表格。

文件树支持按路径、文件名和图表标题搜索。文件新增、删除或改名会自动刷新，隐藏项、符号链接和 Excel 锁文件会被跳过。应用中的表格编辑作用于当前工程。

可以连接 [示例数据文件夹](app/examples) 试用。它包含两批列顺序不同的 CSV 文件。

## 构建桌面应用

使用 Node.js 24。构建时将工具箱检出到与本项目相邻的 tools 目录，光谱分峰依赖其中的 [Voigt 线形工具](../tools/voigt_profile/README.md)。

```sh
cd app
npm ci
npm run desktop
```

执行 `npm run package:mac` 生成本机签名的 Apple 芯片版本，产物在根目录的 [release/个人作图工具箱-darwin-arm64](release/个人作图工具箱-darwin-arm64/)。执行 `npm run lint` 检查源码。

在 `app/` 执行 `npm test` 检查数值计算、导入和撤销行为。执行 `npm run bench` 会生成固定的三份 10 列 CSV 到 `app/examples/bench/`，并测量导入、热力图配置生成、拟合、编辑撤销和 SVG 导出步骤。可在桌面端连接该目录测试 1 万、1.5 万和 10 万行样本。

应用源自 MIT 版本的 SciPlot，保留了[原始许可](app/LICENSE)。[开源调研](docs/upstream.md)和[后续施工方案](docs/roadmap.md)记录了项目背景。第三方参考源码在 `references/`。
